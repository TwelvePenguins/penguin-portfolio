# Portfolio Website

My chemistry and cosmic themed portfolio website, built as an interactive web experience combining traditional frontend development with 3D graphics and animation.

> **Work in progress** — the site is currently under active development.

## Tech Stack

- **React**
- **Vite**
- **Three.js**
- **React Three Fiber**
- **React Three Drei**
- **Lenis**

## Features

- Interactive 3D scenes and animations
- Scroll-based transitions
- Responsive layouts
- Custom 3D components and visual effects

More sections and interactions will be added as development continues.

## Running Locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/TwelvePenguins/penguin-portfolio.git
cd penguin-portfolio
npm install
npm run dev
```

Then open the local development URL provided by Vite.
